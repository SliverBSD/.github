## SliverBSD


SliverBSD is a FreeBSD based operating system that unlike others, does NOT use standard FreeBSD userland,hypervisor and unlike most BSDs we don’t use email for anything, all contributions are done on GitHub. We also try to support as many archetypes as possible and we don’t mainstream any SliverBSD drivers back into FreeBSD. at some point we will support a lot of computers..
